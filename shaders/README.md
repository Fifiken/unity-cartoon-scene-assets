# 卡通/低多边形 Shader 资源

用于实现卡通渲染、低多边形风格的 Shader 集合。

---

## 推荐资源

### 1. LowPolyShaders
- **Star**: 190
- **描述**: 专为 Low Poly 模型优化的 Unity Shader
- **链接**: [BrokenVector/LowPolyShaders](https://github.com/BrokenVector/LowPolyShaders)
- **适用**: 基础低多边形渲染

### 2. polygon-wind
- **Star**: 179
- **描述**: 低多边形资产的风效 Shader（草地、树木摆动）
- **链接**: [renanbomtempo/polygon-wind](https://github.com/renanbomtempo/polygon-wind)
- **适用**: 草地、树木、植被动态效果

### 3. unity-lowpoly-shader
- **Star**: 127
- **描述**: 低多边形网格渲染 Shader（GLSL）
- **链接**: [pavelkouril/unity-lowpoly-shader](https://github.com/pavelkouril/unity-lowpoly-shader)
- **适用**: 平面着色风格的低多边形渲染
