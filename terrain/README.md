# 地形生成工具

用于快速生成低多边形风格地形、地貌的工具集合。

---

## 推荐资源

### 1. Low-Poly-Procedural-Generation
- **Star**: 68
- **描述**: 低多边形地形程序化生成（基于 Sebastian Lague 教程）
- **链接**: [sikozonpc/Low-Poly-Procedural-Generation](https://github.com/sikozonpc/Low-Poly-Procedural-Generation)
- **适用**: 通用地形、草地、丘陵、山地
- **特点**: 程序化生成，可自定义地形参数

### 2. LowPolyTerrainGenerator
- **Star**: 26
- **描述**: 低多边形地形生成器，带生成器/生成区域
- **链接**: [paulSugarr/LowPolyTerrainGenerator](https://github.com/paulSugarr/LowPolyTerrainGenerator)
- **适用**: 快速生成低多边形地形
- **特点**: 可视化生成区域，方便控制地形范围

---

## 按环境使用建议

| 环境类型 | 推荐搭配 |
|---------|---------|
| 🏜️ 沙漠 | 地形生成 + polygon-wind 风效 Shader |
| 🌿 草地 | 地形生成 + polygon-wind 风效 Shader |
| 🏔️ 山地 | 地形生成（调整高度参数） |
