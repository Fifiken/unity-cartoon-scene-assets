# 水体 / 海洋效果

卡通风格的水面、海洋效果 Shader 和系统。

---

## 推荐资源

### 1. Lowpoly-Water-Unity ⭐ 推荐
- **Star**: 510
- **描述**: 低多边形水效果，边缘/海岸混合，类似 Monument Valley 风格
- **链接**: [danielzeller/Lowpoly-Water-Unity](https://github.com/danielzeller/Lowpoly-Water-Unity)
- **适用**: 湖泊、河流、海岸边
- **特点**: 效果优秀，Star 数最高，风格卡通

### 2. LowpolyOcean
- **Star**: 58
- **描述**: 低多边形海洋效果
- **链接**: [JiongXiaGu/LowpolyOcean](https://github.com/JiongXiaGu/LowpolyOcean)
- **适用**: 海洋、大型水域
- **特点**: 专注于海洋场景

### 3. LowPolyWater
- **Star**: 46
- **描述**: 低多边形水面渲染（正弦波叠加 + 平面着色）
- **链接**: [jose-villegas/LowPolyWater](https://github.com/jose-villegas/LowPolyWater)
- **适用**: 小型水面、池塘
- **特点**: 实现简单，易于集成

### 4. Lowpoly-water-for-Unity
- **Star**: 35
- **描述**: Unity 低多边形水效果
- **链接**: [maxwerhahn/Lowpoly-water-for-Unity](https://github.com/maxwerhahn/Lowpoly-water-for-Unity)
- **适用**: 通用水面
