# 完整场景项目示例

包含完整场景的 Unity 项目，可作为参考或直接学习使用。

---

## 森林场景

### 1. HDRP-Forest-Landscape
- **描述**: 使用 Unity HDRP 的中世纪森林环境
- **链接**: [AliEpta/HDRP-Forest-Landscape](https://github.com/AliEpta/HDRP-Forest-Landscape)
- **环境**: 森林
- **渲染管线**: HDRP（高清渲染管线）
- **适用**: 学习 HDRP 下的森林场景搭建

### 2. YokaiForest_Team6
- **描述**: 神秘森林 VR 体验，低多边形风格
- **链接**: [gabriella5264/YokaiForest_Team6](https://github.com/gabriella5264/YokaiForest_Team6)
- **环境**: 森林（日式妖怪风格）
- **特点**: VR 项目，低多边形资产在 Google Blocks 和 Maya 中创建

### 3. Forest-Knight-Game
- **描述**: 森林主题点触游戏
- **链接**: [unnzzz/Forest-Knight---Game](https://github.com/unnzzz/Forest-Knight---Game)
- **环境**: 魔法森林
- **使用素材**: Free Low Poly Nature Forest（Unity Asset Store）
- **特点**: 包含完整游戏逻辑、库存系统、敌人 AI

---

## 如何使用这些示例项目

1. **克隆项目**: `git clone https://github.com/用户名/仓库名.git`
2. **打开 Unity**: 用对应版本的 Unity Hub 打开项目
3. **学习场景**: 打开 Scenes 文件夹下的示例场景
4. **提取素材**: 将需要的模型、材质、Shader 复制到你自己的项目中
