# 3D 模型素材库

开源的低多边形/风格化 3D 模型库，可直接导入 Unity 使用。

---

## 推荐资源

### 1. polyspoon ⭐ 推荐
- **Star**: 96
- **描述**: 开源 AI 驱动的 3D 素材社区，支持 Unity & Godot，低多边形风格
- **链接**: [DITlieD/polyspoon](https://github.com/DITlieD/polyspoon)
- **适用**: 各种环境的道具、建筑、自然元素
- **特点**: 社区驱动，持续更新，人工审核质量

### 2. lowpoly-vault
- **Star**: 4
- **描述**: AI 生成的低多边形 3D 模型集合（Blender），免费游戏素材
- **链接**: [s010s/lowpoly-vault](https://github.com/s010s/lowpoly-vault)
- **适用**: 史前、风格化场景
- **特点**: 全部免费，CC 协议，支持 Three.js/WebGL

### 3. LowPolyShapes
- **Star**: 42
- **描述**: 低多边形基础形状模型库
- **链接**: [keijiro/LowPolyShapes](https://github.com/keijiro/LowPolyShapes)
- **适用**: 基础几何体、占位符
- **特点**: 由知名开发者 keijiro 维护

### 4. LowPolyMedievalAssetsPack
- **Star**: 15
- **描述**: 低多边形中世纪素材包（建筑、道具等）
- **链接**: [passpartout42/LowPolyMedievalAssetsPack](https://github.com/passpartout42/LowPolyMedievalAssetsPack)
- **适用**: 中世纪村落、城堡场景
- **格式**: FBX，支持 Unity / Unreal Engine 4
