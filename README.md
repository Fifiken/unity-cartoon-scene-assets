# Unity 卡通/低多边形风格场景素材资源集合

![Unity](https://img.shields.io/badge/Unity-2018+-blue.svg)
![Style](https://img.shields.io/badge/Style-Cartoon%20%2F%20Low%20Poly-green.svg)

这是一个整理了 GitHub 上开源 Unity 卡通风格、低多边形（Low Poly）场景素材的资源仓库，涵盖**沙漠、草地、森林、海洋**等多种环境类型，帮助你快速搭建卡通风格的游戏场景。

---

## 📂 仓库结构

```
unity-cartoon-scene-assets/
├── README.md          # 本文件
├── RESOURCES.md       # 完整资源索引（推荐先看这个）
├── shaders/           # 卡通/低多边形 Shader 资源
├── terrain/           # 地形生成工具
├── water/             # 水体/海洋效果
├── models/            # 3D 模型素材库
└── scenes/            # 完整场景项目示例
```

---

## 🚀 快速开始

1. 浏览 [RESOURCES.md](./RESOURCES.md) 查看所有整理好的资源
2. 根据你需要的环境类型（森林/沙漠/草地/海洋），从对应分类中选择素材
3. 克隆对应的开源仓库，将素材导入你的 Unity 项目

---

## 🎨 按环境类型速查

| 环境类型 | 推荐资源 | 链接 |
|---------|---------|------|
| 🌲 **森林** | HDRP-Forest-Landscape | [查看](https://github.com/AliEpta/HDRP-Forest-Landscape) |
| 🏜️ **沙漠** | Low-Poly-Procedural-Generation + polygon-wind | [地形生成](https://github.com/sikozonpc/Low-Poly-Procedural-Generation) / [风效](https://github.com/renanbomtempo/polygon-wind) |
| 🌿 **草地** | LowPolyTerrainGenerator + polygon-wind | [地形生成器](https://github.com/paulSugarr/LowPolyTerrainGenerator) / [风效](https://github.com/renanbomtempo/polygon-wind) |
| 🌊 **海洋/水域** | Lowpoly-Water-Unity | [查看](https://github.com/danielzeller/Lowpoly-Water-Unity) |
| 🏘️ **建筑/村落** | LowPolyMedievalAssetsPack | [查看](https://github.com/passpartout42/LowPolyMedievalAssetsPack) |
